# Entendendo o Autismo

Site informativo e educacional sobre o Transtorno do Espectro Autista (TEA), criado para explicar de forma clara e acolhedora o que é o autismo, suas principais características e por que ele não é uma doença, e sim uma condição do neurodesenvolvimento.

## 🎯 Objetivo

Combater desinformação e reforçar uma visão respeitosa sobre a neurodiversidade, mostrando que o autismo:

- Não é uma doença e não precisa de "cura";
- É uma diferença no desenvolvimento neurológico, presente desde o nascimento;
- Se manifesta de forma única em cada pessoa (por isso é chamado de *espectro*).

## 📄 Conteúdo do site

- **O que é o TEA** — explicação geral sobre o espectro autista;
- **Não é uma doença** — desmistificando a ideia de patologia;
- **Principais características** — comunicação, interesses intensos, sensibilidade sensorial, rotina, estereotipias e socialização;
- **Como apoiar uma pessoa autista** — orientações práticas de convívio;
- **Mitos e fatos** — comparação entre crenças populares e informações corretas.

## 🛠️ Tecnologias utilizadas

- **HTML5** com tags semânticas (`header`, `nav`, `main`, `section`, `article`, `figure`, `footer`);
- **CSS3** externo, com variáveis de tema, grid layout e design responsivo;
- Tipografia **Fraunces** (títulos) e **Atkinson Hyperlegible** (corpo de texto), via Google Fonts.

## 📱 Responsividade

O layout se adapta a diferentes tamanhos de tela, com breakpoints para tablets (≤860px) e celulares (≤560px).

## 🚀 Como visualizar

1. Clone este repositório;
2. Abra o arquivo `index.html` em qualquer navegador (mantenha-o na mesma pasta que `styles.css`).

Ou publique gratuitamente pelo **GitHub Pages**: em *Settings → Pages*, selecione a branch `main` e a pasta raiz.
